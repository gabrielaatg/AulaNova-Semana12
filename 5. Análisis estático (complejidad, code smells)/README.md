# Análisis estático — Aula Nova

## Objetivo
Analizar el JavaScript del frontend y backend para detectar problemas de calidad sin ejecutar la aplicación.

## Reglas mínimas sugeridas
`no-unused-vars`, `no-undef`, `eqeqeq` y `no-eval`; establecer límites para complejidad ciclomática y longitud de funciones.

## Ejecución
Se configurará ESLint y un script npm para analizar `app/` y `backend/`.

## Evidencias
Registrar resultados iniciales, clasificar y corregir problemas relevantes, y conservar la comparación con el análisis final.
