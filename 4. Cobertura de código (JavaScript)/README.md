# Cobertura de código — Aula Nova

## Objetivo
Medir statements, branches, functions y lines del código evaluable de la aplicación.

## Metas de la tarea
- Statements: mínimo 80 %.
- Functions: mínimo 80 %.
- Lines: mínimo 80 %.
- Branches: mínimo 70 %.

## Ejecución
Se configurará la cobertura integrada de Jest o Istanbul/nyc mediante scripts de npm.

## Análisis y evidencias
Guardar el reporte HTML generado y documentar los archivos, funciones y ramas con menor cobertura, junto con la comparación inicial y final. Excluir pruebas, dependencias y configuración del cálculo.
