# Pruebas End-to-End — Aula Nova

## Objetivo
Automatizar en un navegador los recorridos principales del estudiante.

## Escenarios a cubrir
Inicio, perfil, cursos, calificaciones, bandeja de mensajes, apertura y envío del formulario, validaciones, navegación entre secciones y recarga de la aplicación.

## Ejecución
Se configurará Playwright para iniciar o utilizar el servidor local y ejecutar los escenarios desde un comando npm.

## Evidencias
`aulanova.e2e.spec.js` incluye 10 recorridos. Playwright guarda reportes HTML/JUnit/JSON y capturas ante fallos bajo `reports/`.
